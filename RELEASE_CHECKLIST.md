# Release Checklist

- Add a `LICENSE` file before publishing if reuse is intended.
- Review `st131-data/` for any data-sharing restrictions before making the
  GitHub repository public.
- Run the lightweight Python checks in the README.
- Generate HMC output locally as needed; do not commit `ST131_HMC_*`
  directories.
- Confirm the GitHub repository description and citation metadata match the
  intended release.
